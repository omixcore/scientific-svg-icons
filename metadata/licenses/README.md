# Licensing records | 授权记录

This directory stores license notes, permissions, and attribution records for third-party assets.

本目录用于保存第三方素材的许可证说明、授权证明和署名记录。

A public repository is not, by itself, a license to reuse its contents. Every imported asset must have a traceable source and a clearly documented license.

仓库公开本身并不构成素材再利用许可。每个导入素材都必须具有可追溯来源和明确记录的许可证。

Until a repository-wide license is selected, `not-assigned` in the icon index means reuse and redistribution rights have not been established.

在确定仓库统一许可证之前，图标索引中的 `not-assigned` 表示尚未确定复用和再分发权利。
