# Metadata | 元数据

[Repository / 仓库主页](../README.md) · [Category directory / 分类目录](../icons/README.md)

[icon-index.csv](icon-index.csv) registers all **520 SVGs**. Each path is relative to the repository root and each ID is unique. 图标索引登记全部 **520 个 SVG**，路径相对于仓库根目录，ID 唯一。

| Field / 字段 | Meaning / 含义 |
| --- | --- |
| id | Unique asset ID / 唯一素材编号 |
| path | SVG source path / SVG 源文件路径 |
| category | Directory category without the icons prefix / 不含 icons 前缀的目录分类 |
| title_en, title_zh | English and Chinese titles / 中英文名称 |
| source, creator | Provenance and creator / 来源与创作者 |
| license | Assigned license or not-assigned / 已确定的许可或尚未确定 |
| status | Review state; draft is not scientific validation / 审核状态，draft 不代表科学性已验证 |

[batches/](batches/) preserves addition records. [path-migrations-20261106.csv](path-migrations-20261106.csv) maps 156 relocated SVG paths. batches 保存新增记录，路径迁移表对应此次移动的 156 个 SVG。历史批次中的路径已同步到当前目录。
